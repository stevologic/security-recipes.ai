{{< callout type="warning" >}}
These recipes do not certify compliance and are not legal advice. They produce
structured evidence and gaps for a compliance owner, auditor, or security
reviewer to map against the current framework version.
{{< /callout >}}

Use these prompts when a team needs a bounded, read-only check that turns
repository evidence, workflow evidence, or policy-as-code into an audit-ready
packet. Each recipe names stop conditions, avoids code changes, and requires a
human owner for any final control mapping.
